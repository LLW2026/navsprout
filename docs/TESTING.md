## 复现

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
npm ci
npx playwright install chromium
.venv/bin/python scripts/check_browser.py
```

浏览器脚本自动启动随机本机端口，随机生成凭据，使用临时数据库。结束后停止子进程并删除数据，日志、结果和截图写入被 Git 忽略的 artifacts 目录。可用 CHROMIUM_PATH 指定已有 Chromium 可执行文件；PLAYWRIGHT_MODULE 可指定已有 Playwright 模块路径。

GitHub Actions 自动执行后端回归及前端 JavaScript 语法检查。需要代理、数据库或调度行为时，以实际运行验证为准，容器启动本身不代表全部功能通过。
