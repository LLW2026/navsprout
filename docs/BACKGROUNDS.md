# 每日网络背景与主题

网站提供 11 种主题和跟随系统，包括磨砂玻璃、纸张纹理、流动极光、柔和阴影与压印标签、终端网格和扫描线。效果由本地 CSS 实现，无第三方脚本或字体。桌面按屏幕宽度调整卡片列数；超宽屏将分类分为两列，置顶横跨两列。

## 每天定时取新图

右上角 ▧ → 图片 →「每日新图」。默认后台任务每天北京时间 06:00 从网络图库选择并下载一张新图片；不需要浏览器打开。任务每 30 秒检查一次到期状态，首次启动、服务器停机错过更新或缓存丢失时自动补取。

```dotenv
NAV_BACKGROUND_ENABLED=true
NAV_BACKGROUND_REFRESH_TIME=06:00
```

修改 `.env` 后执行 `docker compose up -d --force-recreate`。时间采用北京时间（UTC+8），独立于容器的系统时区。格式为 24 小时制 HH:MM。

服务器通过 Lorem Picsum 的 seed/info 取得候选元数据，避开最近 30 张已用图片 ID，下载完整 JPEG 后原子替换索引。以当前每日更新时间窗口为稳定种子，同一天成功后不会反复下载。图片来自现有图库；“每日新图”指每天为导航选择新的图片，不代表当天拍摄或新上传。

页面启用后每分钟查询服务器新记录，发现更新会自动切换，长期开着的页面也会换图。轮播间隔控制缓存图片间的轮播，不改变每天从网络取新图的任务。关闭、隐藏页面时暂停浏览器计时；重新可见后立即检查。外观偏好仅存在浏览器，公网与局域网不同源分别保存；服务器图片与导航数据由两种入口共用。

## 免费图源与许可

2026-10-24 核对并实际请求：[Lorem Picsum](https://picsum.photos/) 提供免密钥的公开图片、种子及元数据接口，图片来自 Unsplash。[Unsplash License](https://unsplash.com/license) 允许免费用于个人和商业项目，禁止原样出售图片、汇编为与其竞争的图库。本项目仅把少量摄影图片用于导航背景，不提供图库检索或下载服务。

网络照片的 ID、摄影者、作品地址、许可、下载时间与 SHA-256 保存在缓存索引，页脚展示当前照片署名与来源。内置的 8 张风景 JPEG 仅作备用，来源逐张保存在 `app/static/backgrounds/catalog.json`。

没有使用 Unsplash API；其 [API 规则](https://unsplash.com/documentation#guidelines--crediting) 对密钥、热链接、署名和下载事件另有要求。Unsplash+ 不作为图源；没有把 Bing 壁纸接口的可访问性当成免费再分发授权。

## 缓存、失败与隐私

- 缓存位于独立挂载的 `data/background-cache/`，保留最近 30 张网络图片，重启或重建容器后保留；不更改导航 SQLite 数据结构。
- 图源或网络失败时保留上一张，并每 10 分钟重试；没有历史图片时使用备用风景。获取失败不阻止应用启动或导航增删改。
- 图片先完整下载、格式和大小检查、落盘，再发布索引。网络客户端只允许 Picsum 及其图片 CDN 的 HTTPS，限制跳转、18 秒请求超时和 6 MiB 上限；不接受用户提交的任意远程图片 URL。
- 浏览器请求本站认证 API，服务器访问图源时不转发浏览器 Cookie、API 令牌或导航内容。照片作者链接只在用户主动点击时打开。
- 关闭「背景动效」停用动画与过渡；系统 `prefers-reduced-motion` 始终优先。图片切换使用双层预加载，旧请求不会覆盖新选择。
- 背景缓存可删除后重建，无需随导航数据库备份；如需保留历史图片，可一并备份整个 data 目录。默认部署单个 Uvicorn 进程管理定时任务。

## 更新备用风景

维护者可调整 `scripts/fetch_backgrounds.py` 的固定 ID 和标题，查看作品并核对许可后运行：

```bash
python3 scripts/fetch_backgrounds.py
docker compose up -d --build
```

该脚本只更新备用图包，日常网络更新由应用后台任务自动执行。无图源账号或密钥需要填写。
